# Canonical Model Notes

Detailed descriptions for each canonical entity in BrkRoutnXdle.

---

# Task

A Task represents a recurring execution intent.

---

# Event

An Event is an instance of a Task or an external event from Google Calendar.

---

# CalendarSlot

Represents an available or occupied time interval within the week.

---

# BlockedSlot

A time interval explicitly blocked by the user.

---

# Schedule

The final result of a week generation.

---

# CalendarSourceEvent

Raw event coming directly from Google Calendar.
