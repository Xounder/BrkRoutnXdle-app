# Calendar & Schedule Fixes — Planning Index

## Objective

Resolve five UI/UX issues in the calendar and scheduling feature of the application. All issues are frontend-only, low-to-medium complexity, and independent of one another.

## Scope

| Issue | Area | Complexity |
|-------|------|------------|
| Font color on event titles | CSS / CalendarStyles | Low |
| Slot creation via inline modal | UI / Calendar feature | Medium |
| Home page scroll behavior | CSS / Layout | Low |
| AM/PM time format setting | Settings / CalendarView | Medium |
| Timezone UTC offset display | Settings / Timezone picker | Low |

## Recommendation

Implement all five fixes independently. No architectural changes required. Each fix targets a specific file or component with isolated scope.
